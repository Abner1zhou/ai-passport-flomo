# flomo 语音备忘客户端 · 操作手册

AI Passport 设备(固件位于 `feature/flomo-client` 分支)上 flomo 语音速记应用
的使用说明:长按一个键录音,设备云端转文字后写入 flomo。无网络时录制的备忘录
会在设备上排队,联网后自动补传。

设备界面为中文,本手册引用的界面文案均与设备一致。构建、分区与验证背景见
[开发者说明](flomo-client.zh_CN.md)。

> [!NOTE]
> 录音质量、小程序配网、转写效果、flomo 写入、中文渲染等设备侧行为尚未在
> 真机验证。本手册描述的是代码实现的行为。

## 使用前提

- 一台已刷入 flomo 客户端固件的 AI Passport 设备。
- **flomo PRO** 账号及其 Incoming Webhook 地址
  (`https://flomoapp.com/iwh/<token>`)。在 flomo 设置中创建 webhook 并复制
  完整地址;webhook 是 PRO 功能。
- 转写服务:任意 OpenAI 兼容的 `/audio/transcriptions` 端点及其 API key。
  默认指向 Groq(`https://api.groq.com/openai/v1/audio/transcriptions`,
  模型 `whisper-large-v3`);任何兼容端点均可。
- **2.4 GHz** Wi-Fi 网络。不支持 5 GHz。
- 手机上的微信,用于配网小程序。
- 同一网络内有浏览器的手机或电脑,用于打开设备配置页。

## 认识设备与按键

设备只有三个按键:**上键(UP)**、**下键(DOWN)**、**确定键(OK)**。

- **单击** = 按下再抬起;**长按** = 持续按住约 1.5 秒。
- 电量百分比显示在屏幕右上角;低于 15 % 时主页追加 `电量低` 提示。
- 15 秒无操作背光熄灭,按任意键恢复(该次按键同时执行其正常功能)。
- **关机**(设置页最后一项)进入深度睡眠。板卡没有已验证的按键唤醒电路:
  唤醒需按复位键或重新上电。

## 屏幕总览

共六个页面;主页单击下键向前翻(主页 → 待传队列 → 设置),单击上键向后翻。
在队列页或设置页,长按上键一定返回主页。设置页内单击上/下键移动选中项,
不翻页。

| 页面 | 如何到达 | 显示内容 | 底部提示 |
| --- | --- | --- | --- |
| 主页 `浮墨速记` | 开机首页;所有"返回"的目标 | Wi-Fi 状态(`未配置`/`配网中…`/`连接中…`/`已连接`/`连接失败`)、待传条数、`电量低` | `按住 OK 录音` |
| 录音中 | 主页长按 OK | 已录时长 `mm:ss`、输入电平百分比 | `OK 结束  上键取消` |
| 转文字/发送 | 录音结束后自动进入 | `转文字中…`,随后 `已同步` 或 `失败·已排队`,停留约 3 秒 | 按键被忽略 |
| 待传队列 | 主页单击下键 | 条数、最老一条时长 `mm:ss`、其尝试次数 `n/5` | `OK 重传  长按删除` |
| 设置 | 队列页单击下键 | 选中列表:`开始配网` / `清除配置` / `关机` | `返回` |
| 配网中 | 设置 → `开始配网` → OK | 配网状态与 SSID;失败显示 `连接失败` | 单击 OK 中止 |

录音页的实际交互是:单击 OK 结束,**单击上键或下键均可取消**(提示文案只
标注了上键)。

| 页面 | 单击上键 | 单击下键 | 单击 OK | 长按 OK | 长按上键 |
| --- | --- | --- | --- | --- | --- |
| 主页 | 上一页 | 下一页 | — | 开始录音 | — |
| 录音中 | 丢弃本段 | 丢弃本段 | 结束本段 | — | — |
| 转文字/发送 | 忽略 | 忽略 | 忽略 | 忽略 | 忽略 |
| 待传队列 | — | — | 立即重试同步 | 删除最老一条 | 返回主页 |
| 设置 | 移动选中项 | 移动选中项 | 执行选中项 | — | 返回主页 |
| 配网中 | — | — | 中止配网 | — | — |

设置页里上键和下键都是把选中项向后移动一项;共三项,最多按两下可达任意
一项。

## 首次配置

### 1. 开机

主页显示 Wi-Fi 状态 `未配置`,待传条数为 0。

### 2. 连接 Wi-Fi(蓝牙配网)

1. 主页单击下键两次进入 `设置`。
2. 单击上/下键,使 `>` 指向 `开始配网`,再单击 OK。设备以蓝牙广播名
   `BLUFI_FoloPassport` 开始广播。
3. 手机打开蓝牙并授予所需权限,打开微信,搜索配套小程序
   [蓝牙配网-FoloToy AI PASSPORT](engineering/wifi-provisioning.zh_CN.md#mini-program-name),
   选中设备,下发 2.4 GHz 网络的名称和密码。
4. 配网页先显示 `配网中…`,成功后显示 `已连接`,失败显示 `连接失败`。
   成功后设备自动回到主页,状态变为 `已连接`;凭证已保存,重启后自动连接。
   单击 OK 可随时中止配网并返回主页。

密码错误、5 GHz 网络或距离太远都会以 `连接失败` 结束,直接重试即可。

### 3. 获取设备 IP 地址

配网完成后设备不会在屏幕上显示 IP。可用两种办法:

- **串口控制台**:用 USB 线连接设备并观察日志;Wi-Fi 连上时 ESP-IDF 会打印
  `sta ip: x.x.x.x` 一行。
- **路由器**:在路由器的 DHCP 客户端列表里查找该设备。

配置页地址跟随 IP 变化,建议在路由器上为设备做静态 DHCP 绑定(IP 保留),
以后不必再找地址。

### 4. 填写配置页

在同一网络的浏览器打开 `http://<设备IP>/`。页面显示待上传队列条数和五个
字段:

| 字段 | 含义 | 规则 |
| --- | --- | --- |
| flomo Webhook | 从 flomo 复制的 Incoming Webhook 地址 | 必填;必须以 `https://` 开头 |
| ASR 接口 URL | OpenAI 兼容转写端点 | 必须以 `https://` 开头;默认 Groq |
| ASR Key | 转写服务的 API key | 必填;以密码框输入 |
| ASR 模型 | 模型名 | 默认 `whisper-large-v3` |
| 语言 | 转写语言提示,如 `zh` | 默认 `zh`;留空表示自动检测 |

点击 `保存`。页面返回 `保存成功` 或 `保存失败`——失败说明某个值非法
(webhook 或端点不是 `https://` 开头)或过长;此时不写入任何数据。

> [!IMPORTANT]
> ASR Key 只写不读:保存在设备上但永不回显到页面。**以后每次保存都要重新
> 填写 ASR Key**,哪怕只改别的字段——表单提交时 Key 为空会清空已存密钥,
> 同步随即停止,直到重新填入。

### 5. 录一条测试

主页长按 OK,说一句话,单击 OK。屏幕依次显示 `转文字中…` → `已同步`,
几秒内 flomo 出现新笔记:内容就是转写原文,不会附加任何标签。

## 日常使用

### 录一条备忘录

1. 主页长按 OK,立即开始录音;屏幕显示已录时长与输入电平。
2. 单击 OK 结束;单击上键或下键丢弃本段。单条录满 120 秒也会自动结束。
3. 结束后进入进度页,显示 `转文字中…`,随后 `已同步` 或 `失败·已排队`,
   停留约 3 秒回到主页。离线或未配置时,约 3 秒后直接回主页,备忘录保留在
   队列中。

### 离线队列

- 队列页显示待传条数、最老一条的时长及其尝试次数 `n/5`。
- 同步自动进行:录音结束后、Wi-Fi 连上时、配置页保存后,以及队列非空时
  约每分钟一轮。
- 失败的备忘录约每分钟自动重试一次。累计 5 次失败后该条被放弃并删除;
  HTTP 4xx 响应(例如 webhook token 失效或过期)会立即放弃。被放弃的备忘录
  无法找回。
- 队列页操作:单击 OK 立即重试同步;长按 OK 删除最老一条;长按上键返回
  主页。
- 容量:队列分区约 5 MB,总共约可存 2.5 分钟音频。存满后新开始的录音会被
  自动取消——先同步或删除若干条,再重新录音。

### 关机

设置 → `关机` 进入深度睡眠。按复位键或重新上电唤醒。队列中的备忘录、
Wi-Fi 凭证与 flomo/ASR 配置全部保留。

## 状态含义与故障排查

| 现象 | 含义 | 处理 |
| --- | --- | --- |
| 配置页显示 `保存失败` | webhook 或端点 URL 不是 `https://` 开头,或某个值过长 | 改正后重新保存 |
| 之后某次保存配置后备忘录不再同步 | 表单以空的 ASR Key 提交,清空了已存密钥 | 重新填入 Key 并保存 |
| 主页显示 `连接失败` | 已存凭证连不上或网络不可达;设备会持续自动重试 | 检查路由器;换网络需重新配网 |
| 录音后显示 `失败·已排队` | 转写或发送时出现网络/服务端错误 | 无需处理:约每分钟自动重试 |
| 队列条数减少但 flomo 没有新笔记 | 某条被放弃:HTTP 4xx(webhook token 失效或过期)、5 次失败,或转写文本超过 3 KB | 到 flomo 检查 webhook 地址;备忘录尽量简短 |
| 录音刚开始就被取消 | 队列分区已满 | 先同步或删除队列中的备忘录再录 |
| 屏幕变暗 | 15 秒无操作的熄屏 | 按任意键 |
| 关机后无法唤醒 | 深度睡眠没有按键唤醒 | 按复位键或重新上电 |
| 配网以 `连接失败` 结束 | 密码错误、5 GHz 网络或距离太远 | 用正确的 2.4 GHz 凭证重试 |
| 重启后主页仍是 `未配置` | 配置已被清除 | 重新执行[首次配置](#首次配置) |

## 隐私与数据

- Wi-Fi 凭证与 flomo/ASR 配置保存在设备 NVS 中。ASR Key 只写不读:永不回显
  到配置页,也永不写入日志。
- 配置页在局域网内使用明文 HTTP。这是明确取舍:设备 IP 动态变化,无法校验
  服务器证书。请只在自己信任的网络中使用。
- 语音备忘录保存在设备闪存中,直到同步成功或被放弃后删除。音频上传到所配置
  的 ASR 端点;转写文本发送到 flomo 的 webhook。
- `清除配置`(设置页)会清空 flomo/ASR 配置与已保存的 Wi-Fi 凭证,但**不会
  删除排队中的音频**;清除后设备回到未配置状态,需重新执行首次配置。

## 规格与限制

| 项目 | 数值 |
| --- | --- |
| 单条时长 | 最长 120 秒,到时自动结束 |
| 录音格式 | 16 kHz / 16 bit 单声道 WAV,约 1.9 MB/分钟 |
| 离线队列 | 总计约 5 MB,约合 2.5 分钟音频 |
| 转写文本 | 上限 3 KB,超长被放弃 |
| 上传尝试 | 每条最多 5 次;HTTP 4xx 立即放弃 |
| Wi-Fi | 仅 2.4 GHz |
| flomo | Incoming Webhook 需要 flomo PRO |
